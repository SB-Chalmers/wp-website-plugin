# SBE website – documentation

This folder holds the documentation for the Sustainable Built Environments website (sb.chalmers.se). It sits inside the site's custom plugin (`sbe-projects`) so it travels with the site when it's synced with WordPress Studio and is there for anyone who pulls the site into Studio or opens it in VS Code.

| File | For | What's in it |
| --- | --- | --- |
| [POSTS-AND-PROJECTS-TUTORIAL.md](POSTS-AND-PROJECTS-TUTORIAL.md) | New editors | One-page quick tutorial: the editor, the boxes in the Add content sidebar, rules, people. Written for Editor accounts |
| [EDITOR-GUIDE.md](EDITOR-GUIDE.md) | Everyone who adds content | How to add posts, projects, resources and people, categories and tags, tag people, manage staff groups |
| [BUILD-NOTES.md](BUILD-NOTES.md) | Whoever maintains the site | How the site is built: plugin, templates, global style changes, layout decisions |

**Shown in WordPress:** the tutorial and the editor guide (and, for administrators, the build notes) are rendered live from these files under **Help** in the admin menu, and the tutorial also in the block editor (? icon, "Help"). Editing a file here changes what editors see; no copy to update.

**Keep it up to date:** when you change how the site works or looks, update the relevant file here (these files are the master copies).

**Public:** files in this folder can be opened by anyone who knows the URL on the live site. Don't put passwords, API keys or personal information here.
