# Add content to the SBE website

*Quick tutorial · version 8, 20 October 2026*

Log in at `sb.chalmers.se/wp-admin`. In the left menu, hover over **Posts** (news, interviews, articles), **Projects** or **Resources** and click **Add New**. Everything you publish appears on the site by itself.

## The editor in one minute

- **Left: the page.** It looks the way it will on the site. Click **Write the title here** and type, press **Enter**, then write the text where it says **Write your text here** (**Enter** = new paragraph, **+** = add a picture, heading or list). Grey text on the page tells you when something is filled in on the right instead (e.g. the second title).
- **Right: Add content.** Fill in the boxes from top to bottom. Closed? Click **Add content** at the top right.
- **Top right: Publish** (twice, to confirm). Later changes: **Save**. Not finished? **Save draft**.

## The boxes in Add content

| Box | What to do |
| --- | --- |
| **Main picture** | **Set featured image** → upload or pick a photo → **Set featured image**. Landscape, important part in the middle. |
| **Status** (projects) | Tick **Ongoing** or **Completed**. *Required*, or the project isn't listed. |
| **Second title** (projects) | Optional subtitle under the title. |
| **Type of post** (posts) | **Post**, **Interview** or **Article**. |
| **Tags** | Type a topic → **Enter**. Pick a suggestion when one appears. |
| **People** | **Add a person** → type a name → click it. Drag to reorder, **×** to remove. They appear under "People involved". |
| **Read more links** (projects) | **Add link** → link text + address. |
| **Publications** | Paste BibTeX → **Add from BibTeX**, or **Add publication** and fill in the fields. Listed under "Publications" on the page; hidden when empty. |
| **Gallery icon**, **Repository** (resources) | Square logo for the Resources page; the GitHub (or similar) link for the "Go to resource" button. |
| **SBE sections** | Videos, key facts, quotes … Click a text block first, then a button: the section is added after it. Type over the example text. |

Clicked a picture in the text? A **Selected picture** box appears at the top: describe the picture in a few words.

## Rules

- One column: stack everything vertically.
- Headings: **Heading 2** for sections, **Heading 3** for sub-sections (type `/heading`).
- External links go in **Read more links**, papers in **Publications**, funding in a **Key facts** section, video titles in the video's caption.
- Pictures: landscape, JPG for photos, PNG for diagrams, no huge files.

## People

**People → Add New Person**: full name at the top, then **Role**, **Profile page** link and **Research interests**, a square **Profile photo** and a **Staff group** (right column) → **Publish**. Someone left? Move them to **Alumni** instead of deleting them.

## Change or delete later

**All Posts / All Projects / All Resources** → click the title → edit → **Save**. To delete: hover over the title in the list → **Trash**.
